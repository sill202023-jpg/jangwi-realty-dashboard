# 장위동 부동산 브리핑 · 1등자이부동산

Tel. 010-6292-2454

블루톤 장위동 공개 대시보드입니다. 2026년 5~10월 공식 실거래 수집본(매매 117건·전세 185건·월세 250건)과 한국부동산원 성북구 주간/월간 지수를 제공합니다.

- 매매·전세·월세 Top10 및 전체 거래내역 검색·정렬·페이지 이동
- 실제 OSM 도로·철도 벡터 배경 내장: 외부 타일 요청 없음
- 추천매물 4개는 설명용 샘플, 등록매물은 방문자 브라우저에만 저장
- 지수는 성북구 전체이며 장위동 단독 지수가 아닙니다
- 일부 단지는 위치 미확인, 일부 세부단지는 단지군 검색 지점으로 표시
- API 키와 서비스 인증값은 포함하지 않습니다. 다른 기간 실시간 조회는 별도 서버가 필요합니다.
